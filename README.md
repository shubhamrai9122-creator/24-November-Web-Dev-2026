# Library Book Manager

A simple, responsive library book manager built with React and Vite. Browse the collection, filter by genre, view book details, and issue or return copies.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run:

```bash
npm run build
```

The app uses local book data in `src/data/books.js`. The included entries are sample data; replace them with the assigned dataset before using this for a class submission. Issue/return changes are kept in React state and reset when the page is refreshed.
